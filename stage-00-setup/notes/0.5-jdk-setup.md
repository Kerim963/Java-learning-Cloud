1. PATH это список папок, где консоль в первую очередь ищет программы. JAVA_HOMЕ содержит корневую папку JDK.
Аналогия PATH: Полки в Кладовой комнате, где вещи рассортированы в определенной порядке.
2. В PATH  добавляют папку bin, потому что она содержит java.exe, javac.exe.
3.
- java -version показывает версию Java.
- where java (Windows) или which java (Linux/macOS) показывает полный путь к java, найденному через PATH.
- javac -version показывает версию компилятора.
4. Разная версия JDK  в консоли и Idea  бывает из-за того, что в консоли используется первая найденная в PATH JDK, а в Idea  можно выбирать JDK  как угодно.
5. Легко перепутать:
PATH и JAVA_HOME
PATH это список папок, а JAVA_HOME это Корневая папка JDK.
java -version показывает версию Java, а javac -version - версию компилятора.
